# Theatre Marquee Quiz Style Guide

## Brand Feel

This template uses one unified game-show stage system for the full video.

- **Intro:** big theatre sign, red curtains, side math panels, gold bulbs, and punchy copy.
- **Quiz and answer reveal:** same stage world, but with static lights and no background motion during thinking time.
- **Conclusion:** recap marquee with the same central board and side-panel framing.

The video should feel like a Grade 11 math game-show poster brought to life, while keeping the actual question screen readable.

## Visual System

- Use red curtains, black stage depth, blue/pink spotlights, neon side formula panels, gold marquee bulbs, and glossy answer bars.
- Keep the central question area warm and legible with a paper-style board.
- Use fixed answer colors: red for A, blue for B, green for C, and orange/gold for D.
- Use green only to identify the correct answer during reveal.
- Side formula panels are decorative context and must not crowd the prompt or answer text.

## Motion

- Intro and conclusion may animate bulbs, spotlights, and confetti.
- Quiz and reveal backgrounds must stay visually still.
- During active questions, the countdown is the only time-based visual element.
- Avoid pulsing lights, moving grids, progress bars, or sweeping effects behind equations during the quiz.

## Reuse Rules

- Future videos should normally change only quiz data.
- Add optional `keyConcept` fields to questions only when the recap should differ from the explanation.
- Any new quiz UI must preserve the show-stage style and the static quiz-frame rule.
