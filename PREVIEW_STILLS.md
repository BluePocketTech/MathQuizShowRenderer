# Preview Stills

Render preview stills into the `out/` folder using `@preview` in the file names so they are easy to spot beside the final video exports.

Each quiz should have 7 preview stills total:

1. Question 1 before answer reveal
2. Question 1 after answer reveal
3. Question 2 before answer reveal
4. Question 2 after answer reveal
5. Question 3 before answer reveal
6. Question 3 after answer reveal
7. Final recap screen

Use file names like:

```text
out/mcr3u-quiz-001@preview-q1-before.png
out/mcr3u-quiz-001@preview-q1-after.png
out/mcr3u-quiz-001@preview-q2-before.png
out/mcr3u-quiz-001@preview-q2-after.png
out/mcr3u-quiz-001@preview-q3-before.png
out/mcr3u-quiz-001@preview-q3-after.png
out/mcr3u-quiz-001@preview-recap.png
```

The question previews should capture the actual quiz layout for each question. The before frame shows the question while the viewer is still thinking. The after frame shows the answer reveal state with the correct answer highlighted.

The recap preview should capture the final recap screen at the end of the video.
